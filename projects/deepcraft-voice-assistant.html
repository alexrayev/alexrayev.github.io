DEEPCRAFT Voice Assistant: Production AWS Architecture

The AWS architecture for an Edge AI product that creates and deploys wake-word and command voice assistants to embedded devices.

Period2022 – present
My roleLed design and development
EmployerInfineon
Live productdeepcraft-voice-assistant.infineon.com

Visit the live product →

The challenge

Give a DEEPCRAFT-branded product, used to build voice assistants (wake word plus commands) for embedded targets, a secure and repeatable production home on AWS.

What I built

  • Led the design and development of the production architecture and deployed the entire stack as infrastructure-as-code with the AWS CDK (TypeScript).
  • Built a multi-AZ VPC that serves the web UI through CloudFront and S3, fronted by an Application Load Balancer.
  • Ran Dockerized User and Admin REST microservices on EC2 Auto Scaling groups, pulled from ECR.
  • Backed the services with a PostgreSQL cluster with read replicas and Alembic-managed schema migrations.
  • Hardened the platform with IAM, ACM/TLS, AWS Secrets Manager, SSO, NAT Gateway egress, SQS, SES and CloudWatch observability.
  • Benchmarked EC2 instance families to optimise per-run model-generation cost and performance.

Architecture

Outcomes

  • Entire environment reproducible from code.
  • Secure-by-default network layout across availability zones.
  • Instance choices backed by cost and performance benchmarks.
