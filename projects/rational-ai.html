Rational AI: Agents for the Software Lifecycle

A generative-AI platform that orchestrates the whole engineering lifecycle through specialised autonomous agents.

Period2022 – present
My roleArchitect, proof of concept
EmployerInfineon

The challenge

Software lifecycle tooling is fragmented. The goal was one AI-driven project that keeps requirements, team, architecture, development, deployment and schedule connected.

What I built

  • Architected, designed and built the proof of concept for a generative-AI platform where specialised, autonomous agents each own a lifecycle phase.
  • Each agent produces structured, traceable artifacts that later phases build on.
  • Integrated large language model providers behind a unified provider abstraction.
  • Exposed tools and context to AI clients through the Model Context Protocol (MCP) for agentic, tool-augmented workflows.
